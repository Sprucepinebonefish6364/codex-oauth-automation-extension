Follow these steps to add the extension to Chrome:

2. Right-click the file and select "Extract All." Choose a folder where you can easily find the extracted files.
3. Open Google Chrome.
4. Type `chrome://extensions` in your address bar and press Enter.
5. Look at the top right of the screen. Toggle the switch for "Developer mode" to the On position.
6. Click the button labeled "Load unpacked" on the top left.
7. Select the folder where you extracted the extension files.
8. The extension icon will now appear in your browser toolbar.

## 🚀 Getting started

Once you successfully install the extension, you can begin using its features. Click the extension icon in your Chrome toolbar to open the main menu.

### Registering accounts
The extension supports automated OAuth registration for OpenAI accounts. When you navigate to the registration page, the tool detects the process. It fills out the necessary fields based on your configuration. If you qualify for a Plus account, the automation handles the sequence to ensure your registration completes without manual input.

### Capturing verification codes
Verification codes arrive via email or SMS during account setup. This tool monitors incoming data streams. When a code arrives, the software extracts the number and enters it into the relevant browser field.

### Handling callbacks
The extension monitors CPA and sub-account callbacks. It validates these status updates against your API requirements. If a connection drops, the tool triggers a recovery sequence. It attempts to restart the session to minimize downtime.

* **Update Chrome:** Ensure your browser is up to date, as older versions may block modern automation scripts.
